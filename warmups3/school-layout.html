Think of this like an architect's top-down drawing of a building. Each room is placed in an exact row and column position. This is a 2D job — CSS Grid is the right tool.

Part 4 — Notice Board CSS Grid

A notice board has notices pinned in rows and columns — a 2D arrangement. Even if you remove one notice, the empty space stays in that exact position. That fixed two-dimensional structure is why Grid is the right tool here.

Part 5 — When to Use Which

Flexbox
  • Desks in a classroom row
  • Lockers along a corridor
  • Books on a single shelf
  • Passengers in one seat row on a bus
  • Items on a factory conveyor belt
→ Things arranged in one direction
Grid
  • Rooms on a building floor plan
  • Notices pinned on a board
  • Seats in a cinema hall (all rows)
  • Plots in a housing colony map
  • Cells in a spreadsheet
→ Things placed in rows AND columns
