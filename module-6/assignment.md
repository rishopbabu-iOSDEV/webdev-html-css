# Module 6: Typography, Color & Backgrounds

## Exercise list

| No. | Exercise | Completion evidence |
|---|---|---|
| 01 | Font Test Drive | Compare two or three fonts on the same heading. |
| 02 | Apply Your Pairing | Assign one heading font and one body font. |
| 03 | Build Your Type Scale | Use rem sizes and readable line height. |
| 04 | Apply Your Palette | Apply background, heading and accent colours. |
| 05 | Style Your Header | Use a readable flat colour, image or gradient background. |

## How to use this folder

- `starter/` contains the safest starting point for the module.
- `warmups/` contains scratch practice separate from the running portfolio.
- `reference/` contains one working module checkpoint. Attempt the task before opening it.
- Continue changes in your own `my-portfolio` folder unless the facilitator asks for scratch practice.
